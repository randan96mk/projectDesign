Workfront Fusion Scenarios

Scenario Name Trigger Action
S1 Intake Request Processing New request submitted Validates request, triggers downstream creation
S2 Marketer Project Creation Request validated Creates marketer project from template
S3 Task Change Watcher Marketer task updated Updates content.js with latest data
S4 Email Governance Watch Governance task complete Triggers sync object generation
S5 Ops Project Creation Governance approved Creates ops project with region/CTA routing
S6 Sync Object & SnapLogic Build task complete Builds MCZ payload, invokes SnapLogic API
S7 Response Processing SnapLogic response received Updates projects with MCZ links, activates QA
