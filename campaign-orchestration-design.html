Mission: Replace fragmented, region-specific manual marketing operations workflows with a unified, governed, and automated orchestration engine — from structured intake to automated MCZ (Marketo) token provisioning — across APAC and AMER.
Shared Design Note: APAC and AMER intake forms share the same solution design and form structure. The only region-specific difference is a small subset of Targeting Criteria fields. All other fields (including Send Date, content sections, CTA fields) are identical across both regions.

Migration Note: When moving from Preview/Stage to Production, each scenario requires: connection updates, template task ID updates, webhook URL updates, and re-activation.
Watch Event Scenarios (S1–S4)
ID Scenario Name Trigger Region Description
S1 New Request – APAC Intake Watch Event APAC Watches for new APAC queue topic submissions; creates Marketer project from APAC template; routes child requests to existing project
S2 New Request – AMER Intake Watch Event AMER Watches for new AMER queue topic submissions; creates Marketer project from AMER template; routes child requests to existing project

Webhook Scenarios (S5–S19)
ID Scenario Name Trigger Description
S5 Targeting – Copy from Last Webhook Pulls targeting data from most recent request by same marketer; populates targeting fields; marks Targeting task complete
S6 Targeting – Copy from Specific Webhook Copies targeting from a specific Request ID provided by the marketer; validates the ID exists; marks Targeting task complete
S7 Targeting – Add Now Submission Webhook Receives inline targeting data from the form; saves region-specific fields to WF custom fields; marks Targeting task complete
S8 Targeting – Provide Later Complete Webhook Triggered when marketer completes the deferred Targeting task; syncs all targeting fields; updates Workfront Planning record
S9 Content – Copy from Last Webhook Copies content.js from most recent request; attaches new document version to Content task; marks Content task complete
S10 Content – Copy from Specific Webhook Copies content.js from specified Request ID; validates document existence; attaches to Content task; marks complete
S11 Content – Add Now Submission Webhook Receives all CTA content (1–5), assembles content.js JSON, attaches as WF Document to Content task; marks task complete
S12 Content – Provide Later Complete Webhook Triggered on Content task completion; assembles content.js from WF fields; attaches document; advances workflow
S13 Validation Summary Builder Webhook Reads content.js; calls Adobe I/O validationSummary; writes results back to content.js; sends Validation email notification
S14 Email Governance Assignment Webhook Assigns Email Governance task; sends notification email to governance team; records assignment in Planning
S15 Email Governance Complete Webhook Triggered on Governance task completion; calls overAllSummary I/O action; advances project to Pre-Build phase
S16 Overview Summary Builder Webhook Calls overviewSummary Adobe I/O action; populates overview section of content.js; sends Pre-Build confirmation email
S17 MCZ Sync Object Builder Webhook Triggered on Pre-Build task 100%; calls mczSyncObject I/O action; assembles 77-token sync payload; stores in content.js
S18 SnapLogic MCZ Provisioning Webhook Sends content.js document ID to SnapLogic webhook; SnapLogic calls Marketo API; provisions tokens in Program Shell
S19 MCZ Response Processor Webhook Calls processResponse I/O action with SnapLogic response; updates content.js; sends Final MCZ Build notification email

Validation Rules

7 enforcement rules applied by the validationSummary Adobe I/O action

SFDC Campaign ID

^701[A-Za-z0-9]{15}$

Must be 18 characters starting with "701" — standard Salesforce Campaign ID format

Preview Text Length

^.{40,130}$

Email preview text must be between 40 and 130 characters for inbox display best practices

Subject Line Length

^.{0,89}$

Email subject line must not exceed 89 characters to avoid truncation in most clients

Email CTA Link

^https://.*

All CTA URLs must be valid HTTPS links — HTTP or missing protocol will fail validation

SFDC Internal Campaign ID

s_iid format

Internal Salesforce campaign identifier format validation — required when SFDC tracking is enabled

Banner Image URL

^https://.*\.(jpg|png|gif|webp)$

Banner image URL must be a valid HTTPS URL pointing to a supported image format

Marketing Hub URL

^https://.*adobe\.com.*

Marketing Hub links must reference adobe.com domain to enforce content governance standards
